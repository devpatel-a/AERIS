# AeroTwin

AI-enabled real-time digital twin for health monitoring, fault prediction and
mission reliability of aero piston engines used in MALE UAVs.

> Status: under active build. See `docs/PLAN.md` for milestone progress and
> `docs/DECISIONS.md` for engineering trade-offs. Full quickstart, screenshots
> and demo walkthrough land in M10.

## Quickstart (early)

```bash
make install   # pip install -e .[dev,ml] + dashboard npm install
make test      # pytest
make lint      # ruff
```
